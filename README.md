# 🚀 TypeSpeeder Enterprise

A Python-based Typing Speed Tester application built using Object-Oriented Programming (OOP) principles and an enterprise-style project structure.

The application measures:

- ⌨️ Typing Speed (Words Per Minute)
- 🎯 Typing Accuracy
- ⏱️ Time Taken
- 📊 Leaderboard Ranking
- 📝 CSV Report Generation
- 📋 Application Logging

This project was built to learn:

- Python OOP
- File Handling
- CSV Processing
- Logging
- JSON Configuration Management
- Exception Handling
- Docker Fundamentals
- Enterprise Project Structure
